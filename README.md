# Quest Basic Kotlin (QuestBasicKotlin_0217)

Proyek ini dibuat untuk memenuhi tugas praktikum **Pertemuan 2 (Basic Kotlin)** menggunakan platform pengembangan Kotlin.

## 📌 Daftar Sub-Bab & Commit History
Proyek ini memiliki riwayat commit yang mendokumentasikan setiap sub-bab materi sesuai dengan modul:
1. `Variables`
2. `Tipe Data Dasar`
3. `Collection` (List, Set, Map)
4. `Conditional expressions` (If, When)
5. `Loops` (Ranges & Loops)
6. `Functions` (Named arguments, default parameters, lambdas)
7. `Class` (Properties, member functions, data classes)
8. `Null safety` (Nullable types, safe calls, Elvis operator)
